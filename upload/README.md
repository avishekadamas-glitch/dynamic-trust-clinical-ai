# Local research inputs

This directory intentionally contains no participant records or study case content.

For the empirical analysis, locally place the authorized original files named:

- `Corrected_Clinical_Trial_Long_Data.csv`
- `Appendix_A_Actual_Sequence.csv`

Both are excluded by `.gitignore`. See `../docs/data_dictionary.md` for the columns
used by the scripts. No public dataset URL or data-access approval is asserted by
this repository. Contact the study authors for the applicable access arrangements.

The mathematical examples and synthetic smoke checks work without these files.
